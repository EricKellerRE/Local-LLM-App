# Grid case analysis

Use the standard MCP tool catalog directly. Staged route/list/schema gateway calls are not required. Do not spawn a second server. Resolve unspecified case paths with workspace.resolve_inputs; ask for clarification if multiple cases fit. Never read binary PowerWorld cases as text.

Directory discovery: pass the user's input directory in case_search_roots and pww_search_roots (directory hints are also supported). Check the returned search roots before concluding files are unavailable. A missing PWW does not block a PWB inventory analysis. When the user requests all cases in a folder, use the candidate list and its count/truncation metadata; do not require one uniquely selected case. A previous failed search outside the requested directory is not evidence that the directory is inaccessible.

Discover canonical fields with case.search_object_fields before exporting records with session.fetch_rows. Entity abbreviations must be resolved from case metadata, not guessed from general knowledge. Distinguish an operator, owner, area, and zone; never assume these are interchangeable. State the attribution basis, entity identifiers, and any missing or ambiguous designation. Shared ownership requires explicit fractions and must not be counted as full ownership for every owner.

Standard catalog reference (schema knowledge, not case facts): the generator object type is `Gen`. Branch identity fields are `BusNum`, `BusNum:1`, and `LineCircuit`; endpoint nominal voltages are `BusNomVolt` and `BusNomVolt:1` (export aliases `NomkVFrom` and `NomkVTo`). `LineLength` is line length; `LineAMVA` is rating A (export alias `LimitMVAA`). Installed generator maximum active capability is `GenMWMax`, not dispatched `GenMW`. Branch `AreaName`/`AreaName:1` refer to from/to bus areas. For Gen, `AreaName` is the generator's area and `AreaName:1` is the terminal bus area; they can differ. Use these known canonical fields directly where applicable and verify returned columns. Search for unfamiliar entity designations or unsupported fields with focused queries; do not repeatedly rediscover known fields. The query tool automatically includes recognized constraint fields and maps their canonical/concise aliases.

Use case.query_objects to retrieve every object matching model-declared constraints. Supply canonical fields, including identity and filtering fields. Constraints use exact exported column headers; if unknown, first query without constraints and limit=1 to obtain columns. Then declare constraints explicitly (AND; use in for alternative values). The matching CSV contains ALL matches even when returned rows are paged. Use matching_row_count, artifact_complete, rows_truncated, and next_offset. Summarize this matching artifact with skip_rows=0, and check its row count against matching_row_count. Do not compute totals from a page. Use host__select_tools when the required query/export/reducer schema is outside the current shortlist.

session.fetch_rows returns a small sample plus an artifact_path, not the entire inventory. Never compute totals from sample_rows, top-N lists, or truncated observations. Use results.summarize_artifact on the full CSV export. PowerWorld SaveData CSV exports have one metadata line before the column header: use skip_rows=1. Use the returned query.fields as the CSV column names. Verify the reducer's source_row_count against the query.row_count. CSV filters are conjunctive; use exact discovered entity identifiers, voltage, status, and branch-type fields as appropriate. Group by a discovered entity field when useful; inspect groups_truncated before treating group results as exhaustive. A missing field, missing numeric value, empty match, or ambiguous attribution is not evidence for a zero total.

For line mileage, identify the length field and units, distinguish circuit miles from route miles, exclude transformers, and apply the requested voltage to both terminals. Do not count reversed endpoint records twice; distinct circuits remain separate. State whether out-of-service equipment is included. Use an explicit entity designation when available; bus area/zone assignments are only a disclosed proxy if appropriate.

Distinguish branch MVA ratings from MW flow and installed generation capability from dispatched MW. MVA/1000 is GVA; an assumed power factor is required to label it GW (GW = MVA * power_factor / 1000). State which rating category is used and flag missing, zero, or sentinel/unlimited ratings. A sum of branch ratings is an inventory metric, not a network transfer capability. Generation installed capacity uses the discovered maximum-capability field, with scope and ownership/operator basis stated. A requested product of total miles and total GW is exactly that product; do not replace it with a sum of individual line rating-times-length products. Preserve full precision until final display.

Report per-case results separately, with all requested entities and metrics, units, definitions, exact case identity and evidence artifact paths. Explicitly mark unresolved quantities instead of inventing values. Follow the user's access restrictions on case contents and outputs.

Reducer usage: results.summarize_artifact returns numeric_columns[column].sum for every numeric column; omit metric unless ranked rows are needed. metric is a column name, never "sum" or another operation. Ordinary CSVs and case.query_objects outputs use skip_rows=0. Use skip_rows=1 only when the tool explicitly identifies a PowerWorld SaveData metadata row. Check all requested metrics and all required input artifacts before giving the final answer.
